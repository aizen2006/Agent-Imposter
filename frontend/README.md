# Agent Imposter — frontend

The Next.js app: game engine, LLM agents, chain integration and match UI.

**Documentation lives at the repo root — see [`../README.md`](../README.md).**

```bash
bun install
cp .env.local.example .env.local
bun run dev
```

Everything in `.env.local` is optional; the app degrades to a stub brain and an
off-chain game rather than failing. See the root README for the full setup,
contract details and troubleshooting.
